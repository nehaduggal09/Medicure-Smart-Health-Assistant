# MediCure Smart Health Assistant

## Project Overview
MediCure Smart Health Assistant is a web-based healthcare assistant developed using HTML, CSS, and JavaScript. The application helps users get basic health-related guidance by entering symptoms and receiving AI-powered suggestions.

## Features
- User-friendly interface
- Symptom input system
- AI-powered health assistance
- Responsive design
- Fast and interactive user experience

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How It Works

1. User enters symptoms.
2. System analyzes the provided information.
3. AI-based prompt generates possible health guidance.
4. Results are displayed in an easy-to-read format.
